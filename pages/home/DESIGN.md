# 首页设计规范 · 极简留白 + 强 Banner + 高级字体层级

## 一、设计 Tokens（已落实到 home.wxss）

| 类别 | Token | 值 | 说明 |
|------|--------|-----|------|
| **颜色** | 页面背景 | `#FAFAFA` | 极浅暖灰，干净 |
| | 主文字 | `#1A1A1A` | 标题、正文主色 |
| | 次文字 | `#7A7A7A` | 说明、辅助文案 |
| | 弱分割 | `#EFEFEF` | 尽量少用 |
| **圆角** | 卡片/按钮/Banner | `24rpx` | 全页统一 |
| **间距** | 左右边距 | `32rpx` | 全页统一基线 |
| | 区块上下（小） | `24rpx` | 标题与内容、卡片间距 |
| | 区块上下（中） | `32rpx` | Banner 与下一区块 |
| **阴影** | 卡片/Banner | `0 12rpx 40rpx rgba(0,0,0,0.06)` | 轻阴影，无描边 |
| **字体** | H1 | `44rpx / 600` | 页面主标题、Banner 主标题 |
| | H2 | `32rpx / 600` | 卡片标题 |
| | Body | `28rpx / 400` | 正文 |
| | Caption | `24rpx / 400` | 辅助说明、Banner 副标题 |

## 二、首页结构（从上到下）

- **A. 顶部区域（安全区内）**
  - 左：页面标题「阅马草堂」H1
  - 右：会员入口（胶囊形、浅底、无描边）
  - 留白分隔，无线框

- **B. Banner 主视觉**
  - 占屏约 42% 宽高比（扁），圆角 24rpx，轻阴影
  - 当前为渐变占位；可替换为真实大图（建议 16:9 或更扁）
  - 叠加文案：主标题 + 副标题（白底/浅色可读）
  - Banner 下方 32rpx 留白

- **C. 功能卡片区**
  - 区块标题「功能入口」Body 级
  - 2 列网格，列间距 20rpx，左右与全页 32rpx 对齐
  - 每卡：纯白底 + 轻阴影，圆角 24rpx，标题 H2 + 一行说明 Caption
  - 重要入口（常规课程、体验课）可加左侧细色条弱强调
  - 卡片与卡片、与标题间距一致

- **D. 底部**
  - 内容区 `padding-bottom` 留出 TabBar 高度 + 安全区，避免被顶住

## 三、强制排版约定

- 全页内容左对齐基线：`padding-left/right: 32rpx`
- 不同时使用「描边 + 阴影」，以轻阴影为主
- 行高：标题约 1.3，正文/说明约 1.4～1.5
- 区块之间用留白分隔，不用线框
- Banner 与卡片圆角统一 24rpx
